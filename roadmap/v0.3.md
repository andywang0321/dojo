# v0.3 — the updating bank

**Shipped:** `dojo fetch <title-slug>` — LeetCode GraphQL intake (HTML → plain text, topic tags → pattern via the shared taxonomy with loud failures on unmapped tags, python3 starter snippet → `function_name` + `signature` hints), seed-file landing, then auto-curation through the v0.2 pipeline (dual-oracle differential + verification gate).

**Taxonomy growth:** five new patterns — linked_list, graph, backtracking, sliding_window, bit_manipulation — in `dojo/patterns.py`, the single source of truth.

**Test discipline:** the whole contract is pinned against canned GraphQL fixtures; the transport is an injected callable, so tests never hit the network.

**Lessons from the first live fetch:** fixtures predicted the response shape correctly, but real content exposed HTML-conversion bugs fixtures missed — `<sup>` exponents flattened into digits ("10^4" → "104", wrong constraints), tab-indented bullets, and whitespace-only lines. Live demos are load-bearing; the fixes are pinned as regressions.
