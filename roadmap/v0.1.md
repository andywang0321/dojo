# v0.1 — the never-solve tutor and empirical grader

**Shipped:** the founding loop — CLI (`init` / `list` / `day` / `check` / `profile`), the problem bank importer, the gated hint ladder (tiers 0–5) with a leak-audit second call, the subprocess-isolated judge (visible + generated + oracle-checked cases), the empirical profiler (doubling sizes, tracemalloc, OLS fit with Occam tiebreak), the three-way complexity comparison, and the rubric reviewer as a separate agent.

**Design bets:** never-solve as an architectural property (oracles never enter tutor context); self-report before measurement; "evidence, not proof" profiler honesty.

**Lessons that stuck:** CPython resizes unshared `s[:-1]` strings in place (a "quadratic" rebuild measures linear); small size ranges make O(n log n) out-fit O(n) — both pinned as tests.
