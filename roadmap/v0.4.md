# v0.4 — deeper grading

**Shipped:**

- **Static analysis at submit** — radon cyclomatic complexity + ruff on every successful submit: shown, stored on the attempt row, re-displayed in `dojo show`, fed to the reviewer as evidence. Complexity > 10 (McCabe) is a flag, never a failure.
- **Per-pattern score trends** — `dojo progress` gains a recency-weighted rubric table from `db.review_trends`.
- **Always-on dual-oracle differential** — `dojo curate` / `dojo fetch` run the curator twice with independent prompts and cross-check the two oracles on generated cases; disagreement rejects the proposal. The oracle is the trust root.

**Dropped deliberately:** the hinted-solution penalty. Penalizing hints would punish asking for genuinely enriching help — hints are the point of the never-solve tutor.

**Lessons:** radon 6 renamed `rank` → `letter` (caught by the tests-first red phase); a trends bug in my own test arithmetic (expected unrounded weighted means of rounded values) — the red-green loop keeps working.
