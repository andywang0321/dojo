# v0.7 — the trust fix and terminal ergonomics

Status: delivered. Triggered by the k_closest_points solve where the judge was wrong and the machine blamed the learner.

**The trust bug:** with a distance tie straddling the k-boundary, equality judging false-failed valid answers twice. Fixed with a `k_closest_valid` checker grading the true "ties may be broken in any order" contract; `top_k_frequent_elements`' generator now enforces its promised unique frequencies. Failed-case display truncates with an ellipsis (a hard cut read as corrupt data).

**Terminal ergonomics:** prompt_toolkit for interactive input (arrow keys, wrapped-line editing, history); bare questions — and command words with extra text — reach the tutor as hints, never "Unknown command"; `de_markdown` handles blockquotes, horizontal rules, and dunder bolds; tutor/discussion token cap doubled; tables gained vertical padding; the tutor is instructed to prefer short paragraphs and plain-dash lists; only ultra-short zero-information messages force the metacognition tier.

**The report command:** `dojo report [slug]` (and in-session `report`) runs a curation audit — fresh curator pass, fresh-vs-live oracle cross-check, and an audit agent hunting prompt-vs-judge contract violations; `--fix` re-curates through the dual-oracle pipeline + verification gate, with full rollback. This run's bug class is exactly what the audit agent is prompted to hunt.

**Lesson:** the student's confidence ("is there something wrong with the grading oracle?") was the bug report. A training tool must earn the right to grade — the report command and the checker-based grading are that contract, both now pinned by tests.
